# Attribution

Lost Cities Reanimated derives from [The Lost Cities](https://github.com/McJtyMods/LostCities), created and maintained by McJty and its contributors. Original source, asset names, building templates, generation algorithms and API identities are retained where compatible. The upstream MIT license is preserved in [LICENSE](LICENSE).

The original 1.12 implementation (2.0.22), the repository's 1.20.1 snapshot, and the inspected 1.21.11 branch are the source references listed in [the backport documentation](docs/backport.md). Portable noise and planning implementations derive from those sources. Changes adapt their behavior to Forge 1.7.10 and 1.12.2 with Java 8.

Universal Adaptive Backporter, Biomes O' Plenty, Underground Biomes and cave-generator integrations remain separate optional projects. Their code and binaries are not bundled in Lost Cities production JARs. Minecraft and Forge are supplied through the version-specific development toolchains and are not redistributed inside the mod JARs.
